Tyagi Mobile Shop - website

Folder structure:
  index.html        - page ka structure (HTML)
  css/style.css     - sara design aur styling
  js/config.js      - dukaan ki jankari: WhatsApp, phone, address, brands, models, reviews
  js/main.js        - brands/accessories cards, model sheet, search, filter, contact
  js/hero3d.js      - 3D golden phone animation (three.js)
  logos/            - brand logo files yahan rakhein

Shuru karne ke liye: js/config.js kholkar SHOP me apna WhatsApp number
(country code ke saath, bina +, jaise 919XXXXXXXXX), phone aur address bharein.
Phir index.html ko browser me kholein. Internet chahiye (fonts aur three.js CDN se aate hain).
